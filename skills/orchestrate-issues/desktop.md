# 실창 검사

프로젝트 설정에 "실창 검사" 절이 있을 때만 쓴다. 데스크톱은 하나라서, 동시 작업자가 실창(실제 창)을 띄우면 서로 가려 캡처와 포커스 검사가 깨진다.

모든 구현·검토 명세에 다음 세 가지를 넣는다.

- 스크린샷은 데스크톱 없이 찍는다(방법은 프로젝트 설정). 화면 캡처는 쓰지 않는다.
- 실창은 프로젝트 설정이 꼽은 꼭 필요한 검사에만 쓴다. 작업 마지막에 한 번 몰아서 한다.
- 실창은 잠금을 잡고 띄운다: `python <홈 절대 경로>/.agent-orchestra/bin/desktop_lock.py run --owner <작업 이름> -- <실창 검사 명령>`.
  - 다른 작업자가 쓰는 중이면 자동으로 기다린다. 15분이 지난 잠금은 넘겨받는다.
  - 잠금 파일은 `~/.agent-orchestra/desktop.lock` 하나다. 프로젝트와 플러그인 버전에 관계없이 같다. 상태는 `desktop_lock.py status`로 본다.
  - 잠금 밖에서 실창을 띄우지 않는다.

## 고정 경로

스킬 폴더 경로에는 플러그인 버전이 들어 있어 업데이트하면 바뀐다. 그래서 잠금 스크립트는 버전과 관계없는 `~/.agent-orchestra/bin/desktop_lock.py`에서 부른다. 저장소 문서나 프로젝트 설정에 실창 명령을 적을 때도 이 경로를 쓴다.

관리자는 지휘를 시작할 때 `python -I <스킬 폴더>/scripts/desktop_lock.py install`을 돌린다. 지금 버전의 스크립트를 고정 경로에 복사한다(같으면 그대로 둔다). 잠금 파일 형식은 버전마다 같으므로, 업데이트 직후 잠깐 이전 사본이 돌아도 서로를 막는 데 문제가 없다.

잠금 대기가 길게 이어지면 새 작업을 시작하지 않는다(SKILL.md 시작 조건).
